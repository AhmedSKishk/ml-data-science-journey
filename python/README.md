# Python

Python exercises covering data types, control flow, and built-in data structures.

## `python-1.ipynb`

**Topics covered:**
- Arithmetic operations with user input via `input()`
- Practical applications: circle circumference (with `math.pi`) and rectangle perimeter
- String operations — indexing, slicing, reversing, escape characters
- Type checking with `type()`

**Tools:** Python · Jupyter Notebook · `math` module

---

## `python-2.ipynb`

**Topics covered:**
- String formatting using f-strings
- String methods — `upper()`, `lower()`, `title()`, `strip()`, `replace()`, `count()`, `index()`/`find()`, `isalpha()`, `isnumeric()`, `isdigit()`, `islower()`/`isupper()`
- Built-in functions — `type()`, `len()`, `input()`
- Conditional logic — simple, nested, and multi-branch `if` statements (e.g. grading systems, age categories, triangle type classification)

**Tools:** Python · Jupyter Notebook

---

## `python-3.ipynb`

**Topics covered:**
- Lists — creation, indexing, slicing, modifying elements, adding/removing items (`append()`, `insert()`, `pop()`, `clear()`), sorting, and combining lists
- For loops — iterating with `range()`, `break`, `continue`, `for-else`, and nested loops
- Combined exercise — looping through a string with nested `if` conditions to classify each character

**Tools:** Python · Jupyter Notebook

---

## `python-4.ipynb`

**Topics covered:**
- While loops with counters (counting up, counting down, custom steps)
- Iterating over a string by index using `len()`
- Loop control with `break` and `continue`
- `while-else` to check whether a character exists in a string (case-insensitive)
- Number series: first 10 numbers (forward and reversed), even and odd numbers, and a descending series with step 7
- Conditional printing inside loops (skipping specific values)
- Mini program: classifies every character of an email (alphabetic lowercase/uppercase, number, special character) using nested `if`, with a `for` loop inside a `while True` loop that repeats until the user answers `N`

**Tools:** Python · Jupyter Notebook
