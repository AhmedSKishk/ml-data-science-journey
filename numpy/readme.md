# NumPy
A folder containing NumPy problems.

## `numpy-1.ipynb`
- Creating arrays: `arange()`, `linspace()`, `random.randint()`
- Reshaping arrays from 1D to 2D with `reshape()`
- Statistical operations: `sum()`, `mean()`
- Element-wise math: `sqrt()`, `exp()`
- Random sampling: `random.uniform()`, `random.rand()`
- Element-wise array comparison

**Tools used:** Python (Jupyter Notebook), `numpy`
