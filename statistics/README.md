# Statistics

Core statistical concepts implemented from scratch using Python's data science stack, with an emphasis on understanding the *why* behind each metric (e.g. population vs. sample calculations), not just the syntax.

## `statistics-1.ipynb`

**Topics covered:**
- Central tendency — mean, median, mode (including multi-modal distributions)
- Dispersion — variance, standard deviation (population vs. sample), range
- Correlation — Pearson correlation coefficient

**Approach:**
Each concept is solved and cross-validated using three different tools — `numpy`, `pandas`, and Python's built-in `statistics` module — to compare syntax, performance, and output consistency across libraries.

**Applied to:**
Realistic scenarios including exam score analysis, weather data, dice-roll frequency distributions, and error-margin estimation.

**Tools:** Python · Jupyter Notebook · NumPy · pandas · statistics
